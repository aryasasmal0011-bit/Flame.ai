# Flame.ai Homepage

Static HTML/CSS/vanilla JS homepage. No build step, no backend.

1. Open `script.js` and paste your Streamlit URLs into `FLAME_CONFIG.links` (top of file).
   Until you do, the card links scroll back to the cards and a console warning lists what is missing.
2. Open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify, etc.).

Fonts (Unbounded, Manrope) load from Google Fonts when online and fall back to system fonts offline.
All icons and artwork are local SVG files in `assets/`.
